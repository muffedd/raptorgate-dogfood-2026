# Results-published webhook (T4 slice)

This is one operator-configured callback, not a REST/webhook API covering every UI action. Set `RESULTS_WEBHOOK_URL` to an operator-controlled HTTPS endpoint on port 443, and set a separate random `RESULTS_WEBHOOK_SECRET` (at least 32 characters). Neither value is accepted from visitors or organizers, stored in the database, or returned from status. Treat the endpoint operator as trusted to receive the event slug. Do not configure a URL you do not control. Do not expose a service capable of making arbitrary outbound network calls to untrusted administrators.

When the organizer first publishes an active event, the same database transaction queues one `results.published` payload with the event slug, only if the endpoint and secret are configured. The browser request makes no outbound call. Run `python src/manage.py dispatch_webhooks` from an operator-controlled scheduler to attempt at most 100 pending deliveries per run. Each POST is UTF-8 canonical JSON with `X-RaptorGate-Delivery` (stable row ID) and `X-RaptorGate-Signature-256: sha256=<hex HMAC-SHA256 of exact body>`. Redirects are disabled so a signed body is not forwarded elsewhere. A successful HTTP 2xx marks delivery; a failed attempt is retained for a later scheduler run. `GET /organizer/webhooks/deliveries` gives the authenticated organizer event-scoped attempts and status, never secrets or endpoints.

Receiver: recompute HMAC on the raw request body, compare with `hmac.compare_digest`, and deduplicate by delivery ID because a timeout can follow a successful receipt. The sender does not guarantee exactly once. Failed callbacks have no effect on the JSONL/HTTP publish result. Retries are manual or operator-scheduled; no background worker is started by the web server. If configuration was absent when results were first published, no callback is backfilled. There is no secret rotation, endpoint management UI, event-by-event subscriptions, or coverage for submissions, votes, comments and judging. HTTP delivery to a real remote endpoint has not been tested; tests mock the network and verify queued state, signature, retries and denial boundaries. This is not full T4.
