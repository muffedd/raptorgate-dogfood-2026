No client-side curl transcript was saved for the retry. This manual diagnostic is not a full automated six-flow sweep and is not included in the unchanged archive. Do not count the archived team-form step as a PASS. Our separate local browser sweep on the tested source confirmed the team flow; see `ACCEPTANCE-SWEEP.md`. The offline VM had no GUI, so the archive's viewport checks are source/HTTP-level, not visual rendering.
